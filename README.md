# C++ Console Calculator

A menu-driven console calculator in C++.

## Features

- Choose add, subtract, multiply or divide from a menu
- Enter two numbers to get the result
- Prints "INVALID INPUT" for an unknown menu choice

## Tech stack

C++

## Getting started

```bash
git clone https://github.com/Matiz009/cpp-console-calculator.git
cd cpp-console-calculator
g++ calculator-c++.cpp -o calculator && ./calculator
```

## Project structure

```
calculator-c++.cpp   Source code
calculator-c++.exe   Old Windows build
```
